# Крестики-Нолики для Telegram

Мини-игра: против бота (непобедимый ИИ на minimax) и онлайн с другом (через комнаты с кодом).

## Структура проекта
- `server.js` — сервер на Express + Socket.io: отдаёт страницу игры и обрабатывает онлайн-режим
- `public/index.html` — сама игра (интерфейс, логика, дизайн)
- `package.json` — список зависимостей

## Как задеплоить (пошагово — см. инструкцию в чате)
1. Залей эту папку в репозиторий на GitHub
2. Разверни её на Render.com (бесплатный Web Service)
3. Скопируй полученный URL вида `https://твой-проект.onrender.com`
4. В @BotFather создай бота и укажи этот URL как Web App в Menu Button
5. Открой бота в Telegram — игра запустится прямо внутри чата

## Локальный запуск (по желанию, для проверки)
```
npm install
npm start
```
Затем открой `http://localhost:3000` в браузере.
